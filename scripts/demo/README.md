# CPCdigital Demo

Öffentliche Browser-Demo von CPCdigital v0.7.6:
[Live-Demo](https://kaizo101.github.io/cpcdigital-demo/)

Die Demo enthält ausschließlich den Webclient, die Poker-Engine und gemeinsame
Typen. Der ruhende Server-Prototyp, lokale Datenbanken, Entwicklungsreferenzen
und interne Arbeitsdateien sind nicht Bestandteil dieses Repositorys.

## Entwicklung

```bash
npm ci
npm test
npm run build
```

Lokalen Webclient starten:

```bash
npm run dev
```
