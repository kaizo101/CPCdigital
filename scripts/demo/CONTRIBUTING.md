# Beiträge zur CPCdigital-Demo

Dieses Repository ist während der Übergangsphase ein automatisch erzeugtes,
öffentliches Abbild des CPCdigital-Webclients. Direkte Änderungen würden beim
nächsten Sync überschrieben.

Fehlerberichte zur aktuell veröffentlichten Demo können als Issue eingereicht
werden. Vermutete Sicherheitslücken oder Zugangsdaten bitte gemäß
[`SECURITY.md`](SECURITY.md) vertraulich melden.

Mit einem Beitrag bestätigst du, dass du die notwendigen Rechte daran besitzt
und ihn unter der

bereitstellst.
